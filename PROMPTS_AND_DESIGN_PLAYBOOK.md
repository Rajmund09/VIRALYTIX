## 1. Main Application & Predictive Analytics Dashboard

### 1.1 2D/3D Particle Wave & Ripple Simulation Canvas
- **Creative Idea**: The background of the predictive dashboard shouldn't be static dark mode—it should feel alive with a physical two-buffer water ripple engine that reacts organically to mouse movement and state changes (analyzing, predicting, completed).
- **Refined Reusable Prompt**:
  > *"Create an interactive HTML5 Canvas background using a true two-buffer wave propagation algorithm (cur, prev, next Float32Arrays). When idle, spawn ambient water droplets with damping of 0.978. When the user moves their mouse, perturb neighboring grid cells to create fluid ripples. Accelerate the wave frequency and amplitude when data processing is active."*

### 1.2 Video Upload Dropzone & Live Audio Spectrum Analysis (Recharts)
- **Creative Idea**: A drag-and-drop video upload zone with real-time video preview, audio waveform scrubbing, and visual progress indicators for multi-stage feature extraction (FFmpeg, Whisper, OpenCV).
- **Refined Reusable Prompt**:
  > *"Build a glassmorphic video upload dropzone supporting MP4 and MOV files. Upon drop, show an animated neon scanning beam, a live video player preview, and an audio spectrum visualizer (Recharts AreaChart) displaying acoustic energy and hook duration across the video's timeline."*

### 1.3 32-D Multimodal Feature Radar & Manual Feature Sliders
- **Creative Idea**: Allow creators to inspect the extracted 32-dimensional feature vector (hook strength, scene cut rate, speech pacing, sentiment polarity, motion vectors) and adjust them manually via interactive sliders to see real-time what-if predictions.
- **Refined Reusable Prompt**:
  > *"Implement an interactive Multimodal Feature Inspector with grouped sliders (Visual, Audio, Speech). Each slider must display the extracted baseline value with smooth spring transitions. When a creator tweaks a slider (e.g. increases Hook Density from 0.4 to 0.9), trigger instant real-time re-inference of the prediction score."*

### 1.4 Persona Swarm Simulation Network & Telemetry
- **Creative Idea**: Simulate a synthetic audience of 6 distinct demographic personas (*Alex the Tech Enthusiast, Sam the Student, Jordan the Founder, Casey the Creator, Morgan the Designer, Riley the General Viewer*) passing through time cascade rounds.
- **Refined Reusable Prompt**:
  > *"Create an agentic Persona Simulation card grid. For each persona, display an avatar badge, interest vector tags, attention span gauge, skip threshold probability, and simulated reaction quotes. Include an interactive 'Run Swarm Simulation' button that animates sequential cascade rounds with live progress rings and engagement score tallying."*

### 1.5 XGBoost Prediction Gauges & Tier Classifications
- **Creative Idea**: Display virality predictions across three distinct dimensions: a continuous 0–100 Virality Index gauge, a discrete performance tier badge (*Viral Breakout, High Engagement, Moderate Reach, Low Retention*), and an expected view count bracket.
- **Refined Reusable Prompt**:
  > *"Design a high-impact Prediction Results panel featuring a radial circular gauge for the 0–100 Virality Index with dynamic color interpolation (Red <40, Amber 40-70, Emerald >70). Display a glowing discrete tier badge with subtle pulsing glow and an estimated view count distribution range."*

### 1.6 SHAP Factor Attribution Waterfall Chart
- **Creative Idea**: Transparently explain the prediction using TreeSHAP factor attribution, highlighting top positive drivers in bright green and top detractors in red with contextual tips on how to improve.
- **Refined Reusable Prompt**:
  > *"Build an explainability panel using SHAP attribution bars. Positive factors (e.g. '+18.4 pts: Strong Hook in first 3s') must display emerald progress bars with checkmark icons. Negative detractors (e.g. '-7.2 pts: Long Silence in midsection') must display red bars with actionable improvement recommendations."*

### 1.7 A/B Video Split-Testing Comparative Mode
- **Creative Idea**: Enable side-by-side comparative mode where creators can upload two video variations (e.g. Variation A vs. Variation B with different hooks) and see exact delta comparisons across all metrics.
- **Refined Reusable Prompt**:
  > *"Implement a side-by-side A/B Comparative Testing dashboard. Render twin upload dropzones, synchronized video players, and delta score badges (+14.2% higher retention in Variant B) with a feature-by-feature diff matrix."*

## 2. Brand Identity & Master Navigation Architecture

### 2.1 Official Logo Integration & Preloader Branding
- **Design Rule**: The official circular brand emblem (`/logo.png`) represents the core visual anchor of VIRALYTIX. No generic icons or placeholder SVGs are used.
- **Preloader Synchronization**: On initial page load, the preloader centers the logo with a smooth circular neon pulse, fading out at $t = 1.6\text{s}$ as the hero content convenes.

### 2.2 Dynamic Rectangular Navigation Bar (`max-w-7xl`, `rounded-[14px]`)
- **Structure**: A floating rectangular container with modern $14\text{px}$ corner radius, spanning up to `max-w-7xl`.
- **Aesthetic**: `bg-[#0A0D14]/85`, `backdrop-blur-2xl`, subtle $1\text{px}$ white rim specular reflection across the top edge (`bg-gradient-to-r from-transparent via-white/40 to-transparent`).

### 2.3 Collapse-Inwards-Into-Logo Scroll Engine & Top-Left Corner Docking
- **The Concept**:
  - At the top of the page, the navbar is an expanded horizontal bar.
  - Upon vertical scroll ($> 60\text{px}$), instead of hiding or splitting in two, **everything collapses inward into the logo**.
  - The container morphs via Framer Motion spring physics (`stiffness: 200, damping: 24, mass: 0.8`) into a compact $56\times56\text{px}$ floating square dock cube (`w-14 h-14 rounded-2xl`).
  - The container shifts from `justify-center` to `justify-start`, docking cleanly to the **top-left corner** (`left-6 top-6`).
  - Clicking the collapsed logo cube smoothly scrolls the viewport back to the top (`window.scrollTo({ top: 0, behavior: "smooth" })`).

### 2.4 Metallic Color Slide Fill CTA ("Launch Engine")
- **Hover Transition**: A multi-stop metallic linear gradient slide fill (`linear-gradient(135deg, #E2E8F0 0%, #94A3B8 50%, #475569 100%)`) that sweeps across the button with zero layout shift on mouse hover.

### 2.5 Production Code: HeroNavigation Component
```tsx
export const HeroNavigation: React.FC<{ onLaunchApp: () => void }> = ({ onLaunchApp }) => {
  const [isScrolled, setIsScrolled] = useState(false);

  useEffect(() => {
    const handleScroll = () => setIsScrolled(window.scrollY > 60);
    window.addEventListener("scroll", handleScroll, { passive: true });
    return () => window.removeEventListener("scroll", handleScroll);
  }, []);

  return (
    <motion.header
      initial={{ y: -60, opacity: 0, scale: 0.95 }}
      animate={{ y: 0, opacity: 1, scale: 1 }}
      transition={{ duration: 0.85, ease: [0.16, 1, 0.3, 1] }}
      className={`fixed top-3 md:top-5 left-0 right-0 z-50 px-4 md:px-8 pointer-events-none flex transition-[justify-content] duration-500 ${
        isScrolled ? "justify-start" : "justify-center"
      }`}
    >
      <motion.div
        layout
        transition={{ type: "spring", stiffness: 200, damping: 24, mass: 0.8 }}
        onClick={() => isScrolled && window.scrollTo({ top: 0, behavior: "smooth" })}
        className={`pointer-events-auto relative flex items-center transition-colors duration-500 border border-white/10 backdrop-blur-2xl shadow-[0_20px_50px_rgba(0,0,0,0.65)] overflow-hidden ${
          isScrolled
            ? "w-12 h-12 md:w-14 md:h-14 rounded-2xl justify-center bg-[#090C12]/95 border-white/20 hover:border-[#00E83F]/70 hover:shadow-[0_0_25px_rgba(0,232,63,0.4)] cursor-pointer hover:scale-105 active:scale-95 p-2"
            : "w-full max-w-7xl justify-between rounded-[14px] bg-[#0A0D14]/85 px-4 md:px-7 py-2.5 md:py-3"
        }`}
      >
        {/* Brand Logo & Wordmark */}
        <div className="flex items-center cursor-pointer select-none group shrink-0">
          <div className="w-8 h-8 md:w-9 md:h-9 flex items-center justify-center shrink-0 group-hover:scale-110 transition-transform">
            <img src="/logo.png" alt="VIRALYTIX Logo" className="w-full h-full object-contain filter drop-shadow-[0_0_10px_rgba(0,232,63,0.55)]" />
          </div>
          <AnimatePresence>
            {!isScrolled && (
              <motion.div
                initial={{ opacity: 0, width: 0, x: -10 }}
                animate={{ opacity: 1, width: "auto", x: 0 }}
                exit={{ opacity: 0, width: 0, x: -25, scale: 0.6, filter: "blur(4px)" }}
                transition={{ duration: 0.35, ease: [0.16, 1, 0.3, 1] }}
                className="flex items-center overflow-hidden whitespace-nowrap"
              >
                <span className="font-sans font-black text-base md:text-lg tracking-tight text-[#F4F1EA] ml-3">
                  viralytix
                </span>
                <div className="h-4 w-[1px] bg-white/20 mx-4 hidden sm:block" />
              </motion.div>
            )}
          </AnimatePresence>
        </div>

        {/* Center Links & Right CTA collapse seamlessly into logo */}
      </motion.div>
    </motion.header>
  );
};
```

## 3. Landing Page: Hero Section & WebGL Canvas

### 3.1 WebGL Silk Fluid Simulation Canvas (`#1E1B4B`)
- **Creative Idea**: An ethereal, high-end WebGL Silk shader background with dynamic Perlin noise fluid distortion that responds gently to mouse cursor proximity.
- **Shader Specs**: `speed={12}`, `scale={1.25}`, `color="#1E1B4B"`, `noiseIntensity={1.8}`, rendered in an `opacity-70` overlay container against deep `#0B0B0A` background.

### 3.2 Hero Kinetic Headline Choreography ("Predict virality")
- **Assembly Timeline**:
  - `t = 0.15s`: Both words assemble in parallel.
  - Characters use custom 3D perspective transforms (`perspective: 1000px`) and `cinemaEase` curves.

### 3.3 Offscreen Replacement Push Badges (`c` and `a`)
- **Letter `c`**: An 8-point razor purple star badge enters from offscreen left (`x: -300 -> 0`), holds for $1.0\text{s}$, and is pushed straight UP offscreen (`y: -120`, `opacity: 0`) as the letter `c` emerges from below (`y: 80 -> 0`).
- **Letter `a`**: An emerald clover badge drops from offscreen top (`y: -250 -> 0`), holds for $1.0\text{s}$, and is pushed straight UP as letter `a` rises with `back.out(1.7)`.

### 3.4 Reciprocal 3D Letter Flips (`i`) & Elastic Vibration (`t`)
- 1st `i`: Flips $360^\circ$ downwards along X-axis (`rotationX: -360`).
- 2nd `i`: Flips $360^\circ$ upwards along X-axis (`rotationX: 360`) in reciprocal counter-direction.
- Letter `t`: Executes a 5-step rapid elastic vibration shake (`rotationZ: ±6°`, `x: ±5px`).

### 3.5 3D Metallic Pill CTA with Symmetric Word Splitting ("GET STARTED ↓")
- **Aesthetic**:
  - Border: Brushed titanium/platinum `rgba(203, 213, 225, 0.32)`
  - Surface: `linear-gradient(180deg, rgba(45, 52, 66, 0.85) 0%, rgba(24, 28, 38, 0.92) 50%, rgba(12, 15, 22, 0.98) 100%)`
  - 3D Bevel & Shadow:
    - Specular top rim: `inset 0 1px 1px rgba(255, 255, 255, 0.35)`
    - Bottom recess: `inset 0 -1px 2px rgba(0, 0, 0, 0.7)`
    - Elevation: `0 6px 16px -2px rgba(0, 0, 0, 0.45)`
- **Symmetric Expansion on Hover**:
  - `GET` glides left by $16\text{px}$ (`-translate-x-4`).
  - `STARTED ↓` (word + arrow) glides right by $16\text{px}$ (`translate-x-4`).
  - The central gap expands smoothly to `w-10 md:w-12`.

### 3.6 Upward V Party Popper Particle Burst Mechanics (`\  /`)
- **The Concept**: On hover, party popper fireworks erupt **directly out of the newly opened gap** between "GET" and "STARTED".
- **Upward V-Formation**:
  - **Vertex Base**: TikTok sticker sits at the lowest center point `(x: 0, y: -58)` right above the gap.
  - **Left Wing**: Instagram ascends at mid-height `(x: -34, y: -86)`; Facebook shoots outward to the top-left tip `(x: -64, y: -114)`.
  - **Right Wing**: YouTube ascends at mid-height `(x: +34, y: -86)`; LinkedIn shoots outward to the top-right tip `(x: +64, y: -114)`.
  - **Confetti & Sparkles**: Streamers shoot along both upward arms up to `y: -140`.
- **Duration & Timing**: Extended to **$1.5\text{s}$** (`times: [0, 0.35, 0.75, 1]`) with floating arc deceleration so each 3D sticker is clearly perceived before dissolving.

## 11. Section 7: 3D Paper Attribution Card (`PaperUnfoldCard`) Architecture

### 11.1 Dual-State Execution (Preserved Entrance + Interactive Mode)
1. **Initial Unfold Phase**:
   - Begins as a tightly crumpled paper ball (`deformMesh(1.0)`).
   - On viewport intersection ($\ge 25\%$), unrolls into the flat card using a smooth cubic ease-out curve ($1 - (1 - \text{rawT})^3$).
   - This entrance sequence is **100% immutable and preserved**.
2. **Interactive Click-and-Hold Mode**:
   - Activates only after entrance completes (`entranceFinished = true`, cursor switches to `grab`).

### 11.2 Click-and-Hold Tactile Crunch (~0.35s)
- Pressing down (`pointerdown`) triggers rapid crumpling into a paper ball (`targetCrumple = 0.95`, speed $8.5$).
- Cursor switches to `grabbing` with pointer capture.

### 11.3 Zero-Lag 1:1 Cursor Dragging Physics & 3D Tilt
- **1-to-1 World Projection**: Because Three.js camera depth is calibrated to screen pixels:
  $$\text{camera.position.z} = \frac{\text{vpHeight}}{2 \cdot \tan(\text{fov} / 2)}$$
  $1\text{px}$ on screen corresponds exactly to $1\text{ unit}$ in Three.js world space.
- **Zero Input Latency**: When dragging, the position is updated instantly without sluggish rubber-band damping (`currentPosX = targetPosX; currentPosY = targetPosY;`).
- **Dynamic 3D Inertial Tilt**:
  $$\text{dragTiltX} = \text{clamp}(-y \cdot 0.0006, -0.25, 0.25), \quad \text{dragTiltY} = \text{clamp}(x \cdot 0.0006, -0.25, 0.25)$$

### 11.4 Smooth Return-to-Center Glide & Unfold on Release
- Releasing anywhere (`pointerup`, `pointercancel`) sets `targetPosX = 0`, `targetPosY = 0`, and `targetCrumple = 0.0`.
- The crumpled ball glides smoothly back to center with return speed $8.5$, simultaneously unfolding back to flat.

### 11.5 GPU-Accelerated Performance Optimization
- **Problem**: Calling `deformMesh` and `geometry.computeVertexNormals()` every frame on mouse move burns 100% CPU.
- **Solution**: Only execute CPU mesh deformation if `Math.abs(currentCrumple - lastDeformedProgress) > 0.001`. While dragging a fully-crumpled ball, the geometry is static; Three.js performs only pure GPU matrix translation at a locked 60/120+ FPS.

### 11.6 Production Code: PaperUnfoldCard Component
```tsx
// Key Interactive Zero-Lag Drag & Spring Return Engine
function runInteractive(time: number) {
  if (disposed) return;
  const dt = Math.min(0.05, (time - lastInteractiveTime) / 1000);
  lastInteractiveTime = time;

  // Tactile crumple physics
  const crumpleSpeed = isHeld ? 8.5 : 6.0;
  const diffCrumple = targetCrumple - currentCrumple;
  if (Math.abs(diffCrumple) > 0.001) currentCrumple += diffCrumple * Math.min(1, dt * crumpleSpeed);
  else currentCrumple = targetCrumple;

  // Zero-lag 1:1 tracking while held, smooth glide back to (0,0) on release
  if (isHeld) {
    currentPosX = targetPosX;
    currentPosY = targetPosY;
  } else {
    const returnSpeed = 8.5;
    const diffX = 0 - currentPosX;
    const diffY = 0 - currentPosY;
    currentPosX += Math.abs(diffX) > 0.2 ? diffX * Math.min(1, dt * returnSpeed) : (0 - currentPosX);
    currentPosY += Math.abs(diffY) > 0.2 ? diffY * Math.min(1, dt * returnSpeed) : (0 - currentPosY);
  }

  // CPU optimization: Only deform vertices when fold amount changes
  if (Math.abs(currentCrumple - lastDeformedProgress) > 0.001) {
    deformMesh(currentCrumple);
    lastDeformedProgress = currentCrumple;
  }

  sheetGroup.position.set(currentPosX, currentPosY, 0);
  const dragTiltX = Math.max(-0.25, Math.min(0.25, -currentPosY * 0.0006));
  const dragTiltY = Math.max(-0.25, Math.min(0.25, currentPosX * 0.0006));
  sheetGroup.rotation.x = 0.14 * currentCrumple + dragTiltX;
  sheetGroup.rotation.y = -0.22 * currentCrumple + dragTiltY;
  sheetGroup.rotation.z = -0.05 * currentCrumple;

  renderer.render(scene, camera);

  const isMoving = isHeld || Math.abs(currentPosX) > 0.2 || Math.abs(currentPosY) > 0.2;
  const isCrumpling = Math.abs(currentCrumple - targetCrumple) > 0.001;
  if (isMoving || isCrumpling) interactiveAnimId = requestAnimationFrame(runInteractive);
  else interactiveAnimId = 0;
}
```
